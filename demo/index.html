Real training runs on your machine

      
This page never trains — it replays the scaffold's deterministic math. To run the actual framework (needs Python and, for real training, GPUs), follow the repo's own quickstart:

      

        
git clone https://github.com/dev4aibots/llm-finetuning-framework.git
cd llm-finetuning-framework
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python main.py
